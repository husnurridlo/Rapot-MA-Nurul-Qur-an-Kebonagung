Panduan Install APK & PWA

Jadikan web ini sebagai aplikasi di Smartphone / Laptop

Untuk HP Android

  1. Buka halaman ini melalui browser Google Chrome.
  2. Klik ikon Titik Tiga (⋮) di sudut kanan atas.
  3. Pilih "Tambahkan ke Layar Utama" atau "Install Aplikasi".

Untuk iPhone / iPad (iOS)

  1. Buka web ini menggunakan browser resmi Safari.
  2. Tap tombol Share (Bagikan) di panel bawah Safari.
  3. Scroll ke bawah lalu pilih "Add to Home Screen".
